# Legacy Notes

Старые корневые заметки перенесены сюда, чтобы очистить hot path репозитория.

Статус:

- содержимое не удалено;
- заметки не считаются текущим playbook;
- перед публикацией или переносом в `content/playbook/` каждую заметку нужно пересмотреть, обобщить и очистить от project-specific деталей.

Правило:

```text
legacy note -> extract reusable pattern -> playbook page or prompt -> archive remains as source material
```
