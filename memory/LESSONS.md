# Lessons

Status: active
Last updated: 2026-06-27

## Reusable

- A public playbook is not enough for agent behavior. Durable process needs a skill, deterministic scripts, starter templates and an audit gate.
- Keep global Codex instructions lean. Store capability truth in registries and project-specific skill use in `docs/SKILLS.md`.
- Readiness must include rules, memory, hooks, skills and communication contracts, not only PRD and architecture docs.
- Capability lists are incomplete without install sources/provenance. Installed skill folders are runtime snapshots, not reproducible sources.
- Plugin config is intent, not proof. Plugin availability requires cache artifacts.

## Candidate Promotions

- Add executable hook enforcement only after the text checklist proves stable across several projects.
