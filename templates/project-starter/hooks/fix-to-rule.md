# Fix To Rule Hook

Run after a painful correction or bugfix.

## Prompt

- Was this one-off or repeated?
- Should it become a rule, checklist, template, test or skill?
- Should it stay project-local or be promoted to shared source_of_truth?

## Output

- no change if too local;
- `memory/LESSONS.md` entry if reusable;
- rule/playbook/hook/template update if proven.
