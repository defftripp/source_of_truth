# Continue Project

## When To Use

Use this when the project already exists and you need to recover context fast.

## Steps

1. Read `AGENTS.md`, `memory/MEMORY.md`, and `memory/SESSION-HANDOFF.md`.
2. Read `develop/README.md`, `develop/IMPLEMENTATION_PLAN.md`, `develop/TODO.md`, `develop/CHECKPOINT.md`, and `develop/LOCAL_RUNBOOK.md` if present.
3. Inspect the active checkpoint spec, prior evidence, local backlog, recent decisions, and latest changed files.
4. Restate the current objective in 1-2 sentences.
5. Name the next smallest useful action and the verification gate.
6. Update handoff and memory when the session ends.

## Output

- short session plan
- active checkpoint and evidence path
- updated memory if context changed
- explicit next action
