# Continue Project

## When To Use

Use this when the project already exists and you need to recover context fast.

## Steps

1. Read `AGENTS.md`, `memory/MEMORY.md`, and `memory/SESSION-HANDOFF.md`.
2. Inspect current backlog, recent decisions, and latest changed files.
3. Restate the current objective in 1-2 sentences.
4. Name the next smallest useful action.
5. Update handoff and memory when the session ends.

## Output

- short session plan
- updated memory if context changed
- explicit next action
