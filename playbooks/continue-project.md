# Продолжение Проекта

## Когда Использовать

Использовать, когда проект уже существует и нужно быстро восстановить контекст.

## Шаги

1. Прочитать `AGENTS.md`, `memory/MEMORY.md` и `memory/SESSION-HANDOFF.md`.
2. Прочитать `develop/README.md`, `develop/IMPLEMENTATION_PLAN.md`, `develop/TODO.md`, `develop/CHECKPOINT.md` и `develop/LOCAL_RUNBOOK.md`, если они есть.
3. Посмотреть active checkpoint spec, prior evidence, local backlog, recent decisions и последние измененные файлы.
4. Пересказать current objective в 1-2 предложениях.
5. Назвать следующий smallest useful action и verification gate.
6. Обновить handoff и memory в конце сессии.

## Выход

- короткий session plan;
- active checkpoint и evidence path;
- обновленная memory, если context изменился;
- явное next action.
