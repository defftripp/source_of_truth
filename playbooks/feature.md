# Feature

## Goal

Ship a new capability without accidental scope creep.

## Steps

1. State the user-visible outcome.
2. Name affected modules, files, or boundaries.
3. Define the smallest vertical slice that proves the feature works.
4. Implement the slice.
5. Verify behavior.
6. Record follow-up work separately instead of silently expanding scope.

## Checklist

- scope is explicit
- success condition is observable
- verification exists
- memory updated if architecture or workflow changed
