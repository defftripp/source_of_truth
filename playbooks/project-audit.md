# Аудит Проекта

## Цель

Найти недостающие основы, которые замедляют startup, maintenance или handoff.

## Зоны Аудита

- canon: `AGENTS.md`, rules, decision records;
- memory: current state, handoff, open questions;
- backlog: actionable tasks с явными outcomes;
- structure: `docs/`, `develop/`, `memory/`, `work/`, `archive/`;
- planning: stage/checkpoint specs со scope, anti-scope, checks и stop conditions;
- agent model: roles, subagent write boundaries, main patch owner;
- automation: hooks, scripts, scheduled maintenance;
- verification: checks, tests, evals, browser smoke steps;
- evidence: durable artifacts, linked heavy files, status и next step.

## Выход

- top gaps;
- risk level;
- next 3 highest-value fixes.
