# Fix To Rule Hook

Run this after a bugfix or painful correction.

## Prompt

Ask:

- Was this a one-off or a repeating pattern?
- If it can repeat, should it become a rule, checklist item, or template?
- Where should that lesson live: `rules/`, `playbooks/`, `hooks/`, or the starter template?

## Output

- no change if the lesson is too local
- new reusable artifact if the lesson generalizes
